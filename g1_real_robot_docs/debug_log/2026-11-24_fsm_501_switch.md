# 2026-11-24 G1 切换到 FSM 501 命令记录

目的：`05_web_navigation.sh` 的实机导航 SDK（`scripts/real_robot/g1_navigation_sdk.cpp`）只接受 **FSM 501**，
其它模式会直接打印 `REJECTED FSM_NOT_501` 退出。本文记录在 PC2（unitree@172.18.14.107，eth0 192.168.123.164）
读取与切换 FSM 的命令、实测结果和候选流程。

## 1. 读取 / 切换工具（已构建，可直接复用）

源码：`scripts/real_robot/g1_fsm_tool.cpp` → PC2 产物 `/home/unitree/ldy/g1_real_data/bin/g1_fsm_tool`

重新编译（在 PC2 上，**不要** source ROS）：

```bash
SDK=/home/unitree/ldy/FAST_LIO_LOCALIZATION_HUMANOID/.deps/src/unitree_sdk2
env -u LD_LIBRARY_PATH g++ -O2 -std=c++17 \
  -I$SDK/include -I$SDK/thirdparty/include -I$SDK/thirdparty/include/ddscxx \
  -L$SDK/lib/aarch64 -lunitree_sdk2 \
  -L$SDK/thirdparty/lib/aarch64 -lddscxx -lddsc -lpthread \
  -Wl,-rpath,$SDK/thirdparty/lib/aarch64 \
  -o /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool \
  /home/unitree/ldy/FAST_LIO_LOCALIZATION_HUMANOID/scripts/real_robot/g1_fsm_tool.cpp
```

读取当前 FSM / 模式：

```bash
env -u LD_LIBRARY_PATH /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool eth0 get
# 期望输出形如：fsm_id_result=0 fsm_id=802 fsm_mode_result=0 fsm_mode=0
```

设置 FSM（含 10 次读回确认，落地成功才返回 0）：

```bash
env -u LD_LIBRARY_PATH /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool eth0 set 501
```

注意：必须 `env -u LD_LIBRARY_PATH`；若 shell 里 source 过 /opt/ros/foxy/setup.bash，
Foxy 自带 CycloneDDS 0.7 会与该 SDK 冲突导致 DDS 通信失败。

## 2. 实测结果（2026-11-24 17:12-17:14）

- `get`：`fsm_id_result=0 fsm_id=802 fsm_mode_result=0 fsm_mode=0`（DDS 正常，eth0 可达）
- `set 501`：`before fsm_id=802 fsm_mode=0` → `SetFsmId(501)=0`（服务端接受）
  → readback[0..9] 全部 `fsm_id=802`，工具 exit=3。
- 结论：**802 → 501 被应答但未落地**，与 cyberwave 文档描述的
  `Transition acknowledged but FSM 501 not confirmed` 同型，需要中间状态（推测 FSM 4 Lock stand）。

## 3. 文档给出的正规流程（需要现场遥控器）

参考：https://cyberwave.com/unitree/unitree-g1/get-started.md ，
https://roboticsknowledgebase.github.io/wiki/common-platforms/unitree-g1/

FSM 501 = Regular mode，官方要求从 Lock stand（FSM 4）进入，且机器人静止站立、手臂释放、导航自主禁用：

1. 遥控器 **L2 + B** → Damping（阻尼，FSM 1）
2. 遥控器 **L2 + Up** → Lock stand（锁定站立，FSM 4）
3. 在机器人板载机执行 `/home/unitree/carry mode regular`
   （打印 `Current FSM: 4` / `Regular mode confirmed (501)`）
   - 本机 **没有** `/home/unitree/carry`，这一步无法照抄，需替代手段或厂商工具。

## 4. 候选路径（未执行，需现场确认）

用 SDK 走中间态：

```bash
# 机器人已站立、静止、周围无人、急停在手
env -u LD_LIBRARY_PATH /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool eth0 set 4    # Lock stand
env -u LD_LIBRARY_PATH /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool eth0 get      # 确认 fsm_id=4
env -u LD_LIBRARY_PATH /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool eth0 set 501  # Regular
env -u LD_LIBRARY_PATH /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool eth0 get      # 确认 fsm_id=501
```

风险：从 802 进入 4 可能触发站立/锁定动作，必须在吊架或有人看护、急停可用的情况下做；
若 4→501 仍不落地，说明该转换只能由遥控器/官方 App 完成。

SDK 侧 helper 对应关系（`g1_loco_client.hpp`）：Damp=1、Squat=2、Sit=3、StandUp=4、Start=500、ZeroTorque=0；
错误码 7301 = LocoState not available，7302 = Invalid fsm id。

## 5. 切换后的验证

```bash
env -u LD_LIBRARY_PATH /home/unitree/ldy/g1_real_data/bin/g1_fsm_tool eth0 get   # 应为 fsm_id=501
curl -s http://127.0.0.1:18081/api/state | head -c 400                          # 05 Web 仍 idle，可点“开始实机导航”
```

只有 501 确认后，`g1_navigation_sdk` 才会通过 `permitted()` 检查并接受导航速度指令。

## 6. 现场安全要求

- 记录现场人员、停止手段、机器人是否吊架/落地。
- 切换期间保持导航自主速度禁用（05 Web 不要点“开始实机导航”）。
