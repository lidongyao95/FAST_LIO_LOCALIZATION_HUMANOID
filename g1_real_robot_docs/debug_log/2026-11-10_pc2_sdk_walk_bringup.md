# 2026-11-10 PC2 实机 SDK 起步与停车

机器人由吊架保护，主运控读数为 `fsm_id=802`、`fsm_mode=0`。模式切换由现场遥控器完成，PC2 只读确认。ROS 2 零速服务调用 SDK 返回成功，现场确认静止时没有动作。

## 实机对照

遥控起步、松杆并停稳时，第一段 FAST-LIO 里程计记录到约 27 cm 净位移。第二次同步从 `rt/lowstate` 读取遥控输入，前向摇杆峰值约 95%，离中约 4 秒，约 0.70 秒后里程计首次偏离起点 3 cm。摇杆量没有 m/s 标定。

SDK 测试使用 PC2 `eth0`，约每 100 ms 刷新一次速度，每条请求有效期参数为 300 ms，结束时显式请求零速。录包为 PC2 本地临时数据。

## 提交范围

- 独立速度桥默认禁用，非零输出仍为 dry-run。真实定位健康可选用 Open3D 逐次配准结果及新鲜点云和里程计。显式零速服务可调用 SDK 零速入口。
- SDK 只读预检和零速入口单独运行。ROS 桥和 SDK 发送适配层的前向上限均设为 0.30 m/s。
- 非零实机结果来自现场调试程序，持续速度桥的实机非零发送尚未接线。速度流中断、机器人链路中断、遥控接管和自主导航仍待验收。
