# PC2 无初值自动重定位

04 localize 默认不读人工初值。启动传感器/LIO 后采集三组不重叠、时间递增且新鲜的 camera_init 点云。独立 Open3D C++ 工具用 FPFH/RANSAC 和重力对齐的全图平移/朝向相关性搜索提案、全图 ICP 复核，多个地图区域产生竞争候选；评分不足、RMSE 过大或空间分离的相似候选均拒绝。候选须通过后两组扫描的重叠率和小修正检查，才转成 map←camera_init 初值交给现有持续定位节点。不发布搜索中的候选 TF；持续定位完成初始化前不发布地图位姿。人工 --initial 仅保留为显式调试入口。

边界：几何相似区域可能无法辨别，候选搜索是有界的而非穷尽证明。需要机器人暂时静止；失败保留数据、日志并退出，不驱动硬件。验证使用未知大平移/转角的真实地图裁剪、无重叠、重复结构歧义、独立实时扫描；同源/合成结果不代表独立现场精度验收。
