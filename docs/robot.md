# 真机部署

在真实的 G1 上建图，然后在网页上点目标让它走过去。

开始前先完成[环境配置](setup.md)的第二部分。下面的命令都在 PC2 上运行：

```bash
ssh unitree@<PC2 地址>
cd ~/ldy/g1_slam
```

机器人行走时，旁边要有人看着，遥控器拿在手里，随时可以按急停。

## 第一步：检查

```bash
./g1_slam robot check
```

显示“PC2 环境检查通过”再继续。

## 第二步：建图

给这张地图起个名字，比如 `maze01`：

```bash
./g1_slam robot map maze01
```

程序会启动雷达和 FAST-LIO。看到“开始建图”后：

1. 用遥控器让机器人把要导航的区域走一遍，走慢一点，最后回到出发点附近。
2. 回到终端按**回车**。

程序保存点云并导出地图，结束时显示“地图已导出”。地图在 `~/ldy/g1_real_data/maps/maze01/`。

建图时场地里尽量不要有人走动，走动的人会被当成障碍留在地图上。

## 第三步：导航

### 1. 让机器人进入运控模式 501

导航程序只在模式 501（常规行走）下给机器人发速度。查看当前模式：

```bash
./g1_slam robot fsm get
```

如果 `fsm_id` 不是 501：用遥控器按 `L2+B` 进入阻尼，再按 `L2+↑` 进入锁定站立，然后运行：

```bash
./g1_slam robot fsm set 501
```

命令会读回确认。读回的不是 501 时，改用遥控器或宇树 App 切到常规行走模式，再用 `fsm get` 确认。

### 2. 启动导航

把机器人放在地图范围内，保持静止，运行：

```bash
./g1_slam robot nav maze01
```

程序会自己找到机器人在地图上的位置（一两分钟），再启动导航和网页。结束时打印两行内容：一条 `ssh -N -L ...` 命令和一个网址。

### 3. 打开网页

在**你自己的电脑**上新开一个终端，运行刚才打印的 `ssh -N -L ...` 命令，保持它运行。然后用浏览器打开：

```
http://127.0.0.1:18081/
```

网页上能看到地图、机器人的位置箭头和实时雷达点。先确认雷达点和地图上的墙对得上，然后：

1. 在地图上点一个目标。
2. 点**规划路径**，看路线是否合理。
3. 点**开始实机导航**，机器人开始走。
4. 随时可以点**取消并停车**。

关掉网页、网络断开或定位丢失时，机器人会自动停下。

在 PC2 的终端按 `Ctrl+C` 结束导航。

### 只看路线，不让机器人走

```bash
./g1_slam robot nav maze01 --plan-only
```

网页只显示规划的路线，适合先检查地图。

## 查看状态

```bash
./g1_slam robot status
```

依次报告雷达、FAST-LIO、定位和运控模式是否正常。

## 现场有人走动时建图（可选）

普通建图会把走动的人留在地图上。DUFOMap 可以把这些动态点去掉，它需要逐帧的扫描数据，并且只能在 x86 电脑上运行。

1. 建图的同时，在 PC2 另开一个终端采集扫描（`X Y Z` 是雷达相对机体的位置，单位米）：

   ```bash
   ./g1_slam robot scans maze01 --lidar-in-body X Y Z
   ```

2. 把 `~/ldy/g1_real_data/scans/maze01` 拷到 x86 电脑，清理并导出：

   ```bash
   ./g1_slam robot clean 扫描目录 maze01_clean
   ```

3. 把导出的 `maze01_clean` 目录拷回 PC2 的 `~/ldy/g1_real_data/maps/`，用它导航。

## 出问题时

每次运行的日志在 `~/ldy/g1_real_data/records/workflows/` 下最新的目录里。

| 现象 | 处理 |
| --- | --- |
| 提示“地图名已经用过” | 换一个名字，旧数据不会被覆盖 |
| 定位超时 | 看 `localization.log`；确认机器人在地图范围内，周围和建图时差别不大 |
| 网页提示 `FSM_NOT_501` | 按“第三步 1”切到 501 |
| 网页打不开 | 确认 `ssh -N -L` 那个终端还在运行 |
| 提示已有程序在运行 | `python3 shared/processes.py --stop --domain 223` |
